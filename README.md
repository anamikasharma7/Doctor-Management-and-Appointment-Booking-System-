🏥 Doctor Management & Appointment Booking System (MERN)

A full-stack MERN application that allows patients to book appointments with doctors and enables admins/doctors to manage schedules efficiently.

🚀 Tech Stack

Frontend

React.js

Axios

HTML5, CSS3

Bootstrap / Tailwind (if used)

Backend

Node.js

Express.js

Database

MongoDB (Mongoose)

Tools

Git & GitHub

Postman (API testing)

✨ Features

👤 User (Patient)

User registration & login

View available doctors

Book doctor appointments

View appointment status

👨‍⚕️ Doctor

Doctor login

View assigned appointments

Manage availability

🛠️ Admin

Add / update doctors

View all users & appointments

Manage system data
